como puedo hacer ahora que algunas pantallas no esten en landscape?

¡Perfecto! Ya tienes el 90% del trabajo hecho al tener el manifiesto configurado. Ahora, como el `AndroidManifest` manda sobre toda la aplicación, necesitamos "engañar" a la Activity desde el código de Kotlin para que cambie de opinión cuando entres en pantallas específicas.

En Jetpack Compose, la mejor forma de hacer esto es usando un **`DisposableEffect`**. Esto permite que, al entrar a una pantalla, la orientación cambie a vertical y, al salir de ella (cuando el usuario vuelve atrás), regrese automáticamente a horizontal.

Aquí tienes el código que debes copiar y cómo usarlo:

### 1. La función mágica (Copia esto)
Puedes poner esta función fuera de tus clases o en un archivo de utilidades. Es la que se encarga de hablar con el sistema operativo:

```kotlin
import android.app.Activity
import android.content.pm.ActivityInfo
import androidx.compose.runtime.Composable
import androidx.compose.runtime.DisposableEffect
import androidx.compose.ui.platform.LocalContext

@Composable
fun LockScreenOrientation(orientation: Int) {
    val context = LocalContext.current
    DisposableEffect(orientation) {
        val activity = context as? Activity
        val originalOrientation = activity?.requestedOrientation
        
        // Cambiamos a la orientación deseada
        activity?.requestedOrientation = orientation
        
        onDispose {
            // Al salir de esta pantalla, restauramos la original (landscape)
            if (originalOrientation != null) {
                activity.requestedOrientation = originalOrientation
            }
        }
    }
}
```

---

### 2. Cómo usarlo en tus pantallas verticales
Ahora, en la función `@Composable` de la pantalla que quieras que sea vertical, simplemente invoca la función al principio:

```kotlin
@Composable
fun PantallaVertical() {
    // Esto forzará vertical solo para esta pantalla
    LockScreenOrientation(ActivityInfo.SCREEN_ORIENTATION_PORTRAIT)

    Column {
        Text("¡Hola! Soy una pantalla vertical.")
    }
}
```

---

### ¿Por qué hacerlo así?
1.  **Automático:** No tienes que preocuparte de "limpiar" el cambio. Gracias al `onDispose`, cuando el usuario navega a otra pantalla o pulsa "atrás", la aplicación vuelve a ser `landscape` ella sola.
2.  **Seguro:** Al usar `context as? Activity`, evitas que la app se cierre si por alguna razón el contexto no es una actividad (aunque en Compose suele serlo siempre).

### Un detalle importante:
Cuando fuerces la orientación a vertical en una pantalla específica, el dispositivo **rotará físicamente** la interfaz. Asegúrate de que el diseño de esa pantalla esté preparado para verse bien en vertical (usando `Modifier.fillMaxSize()`, por ejemplo).

y este codigo en que paquete de la captura deberia de ponerlo?

Para mantener tu proyecto organizado y seguir las buenas prácticas de arquitectura en Android, **no deberías mezclar este código con tus pantallas (UI) ni con la lógica de negocio**.

Mirando la estructura estándar de un proyecto de Kotlin/Compose, tienes un par de opciones ideales:

### Opción A: Crear un paquete de utilidades (Recomendado)
Lo más limpio es crear un paquete nuevo llamado `util` o `common`. 

1.  Haz clic derecho sobre tu paquete principal (donde está `MainActivity`).
2.  Selecciona **New > Package** y llámalo `util`.
3.  Dentro de `util`, crea un archivo Kotlin llamado **`OrientationUtils.kt`**.
4.  Pega allí el código de la función `LockScreenOrientation`.

**¿Por qué aquí?** Porque es una herramienta técnica que podrías usar en cualquier parte de la app, y así no "ensucia" tus archivos de interfaz.

---

### Opción B: En el paquete `ui` (Si es un proyecto pequeño)
Si prefieres no crear carpetas nuevas, puedes ponerlo dentro del paquete **`ui`**, pero te sugiero crear un archivo específico para ello:

1.  Ve a la carpeta **`ui`**.
2.  Crea un archivo llamado **`ScreenUtils.kt`**.
3.  Pega el código allí.

---

### Cómo quedaría tu estructura (Resumen):

* `com.tu.paquete`
    * `ui` (Tus pantallas/Composables)
        * `PantallaVertical.kt` (Aquí **usas** la función)
        * **`ScreenUtils.kt`** (Aquí **pegas** el código de la función)
    * `MainActivity.kt`

---

### Un recordatorio importante al usarlo:
Cuando vayas a usar la función en una de tus pantallas (que estarán en otro archivo), Android Studio te pedirá que **importes** la función. Solo tendrás que pulsar `Alt + Enter` sobre el nombre `LockScreenOrientation` y él solo añadirá el `import com.tu.paquete.util.LockScreenOrientation`.

como mostrarias un popUp que diga campos inscorrectos introducelos de nuevo? (debe desaparecer con el tiempo)

Para mostrar un mensaje que aparece y desaparece solo con el tiempo en Android, la herramienta estándar y más sencilla es el **Snackbar**. Es mucho más moderno y menos intrusivo que el antiguo "Toast".

Dado que estás usando **Scaffold** (por lo que vi en tu código de la `TopBar`), lo ideal es usar el `SnackbarHostState`.

Aquí tienes los 3 pasos para implementarlo:

### 1. Preparar el Scaffold
Primero, necesitas un "gestor" de estados para los mensajes. En tu pantalla donde tengas el `Scaffold` (probablemente `MainScreen` o `MainActivity`), añade esto:

```kotlin
val snackbarHostState = remember { SnackbarHostState() }

Scaffold(
    snackbarHost = { SnackbarHost(hostState = snackbarHostState) }, // <--- Esto es vital
    topBar = { MenuTopBar(SEState) }
) { paddingValues ->
    // Tu NavHost o contenido
}
```

---

### 2. Función para lanzar el mensaje
En Compose, lanzar un mensaje es una "acción suspendida", por lo que debe ir dentro de un `scope.launch`. Puedes modificar tu `loginButtonAction` (o la de registro) así:

```kotlin
fun loginButtonAction(
    // ... tus otros parámetros ...
    snackbarHostState: SnackbarHostState, // Añade este parámetro
    scope: CoroutineScope
) {
    scope.launch {
        val loginSuccess = cF.loginRegisterCase.iniciarSesion(emailForm, passwordForm)
        
        if (loginSuccess) {
            prepareScreenOrientation(SEState, ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE)
            SEState.goTo(Destinos.JUGAR_CREAR)
        } else {
            // Muestra el mensaje que desaparece solo
            snackbarHostState.showSnackbar(
                message = "Campos incorrectos, introdúcelos de nuevo",
                duration = SnackbarDuration.Short // Desaparece tras unos segundos
            )
        }
    }
}
```

---

### 3. ¿Y si quieres algo más visual (un Pop-Up real)?
Si prefieres un diseño propio que flote sobre la pantalla y desaparezca solo (sin usar la barra del sistema), puedes usar una **Animación de Visibilidad**.

Dentro de tu `LoginScreen`, añade este estado:

```kotlin
@Composable
fun LoginScreen(...) {
    var mostrarError by remember { mutableStateOf(false) }

    // Efecto para esconder el error automáticamente tras 3 segundos
    LaunchedEffect(mostrarError) {
        if (mostrarError) {
            delay(3000)
            mostrarError = false
        }
    }

    Box(modifier = Modifier.fillMaxSize()) {
        // ... Tu Column con los campos ...

        // El "Pop-up" animado
        AnimatedVisibility(
            visible = mostrarError,
            enter = fadeIn() + slideInVertically(),
            exit = fadeOut() + slideOutVertically(),
            modifier = Modifier.align(Alignment.BottomCenter).padding(bottom = 50.dp)
        ) {
            Surface(
                color = Color.Red.copy(alpha = 0.8f),
                shape = RoundedCornerShape(8.dp),
                tonalElevation = 4.dp
            ) {
                Text(
                    "Campos incorrectos, introdúcelos de nuevo",
                    color = Color.White,
                    modifier = Modifier.padding(16.dp)
                )
            }
        }
    }
}
```

**¿Cuál prefieres?** El **Snackbar** (Opción 1) es lo que Google recomienda por accesibilidad y diseño limpio, pero la **Opción 3** te da control total sobre los colores y la posición del mensaje.
