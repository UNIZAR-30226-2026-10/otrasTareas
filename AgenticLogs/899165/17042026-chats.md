Para filtrar una lista en Kotlin basándote en una propiedad de los objetos que contiene, la forma más directa y legible es utilizar la función de extensión `.filter`.

Aquí tienes cómo hacerlo:

```kotlin
val casillaBuscada = 5 // El Int por el que quieres filtrar

val fichasCasilla = fichas.filter { it.casilla == casillaBuscada }
```

### Opciones según lo que necesites:

1.  **Obtener solo una (la primera que encuentre):**
    Si sabes que solo debería haber una ficha en esa casilla o solo te interesa la primera, usa `find`:
    ```kotlin
    val fichaUnica = fichas.find { it.casilla == casillaBuscada } 
    // Devuelve FichaSnapshot? (nullable)
    ```

2.  **Si necesitas filtrar y transformar al mismo tiempo:**
    Si por ejemplo solo quieres los IDs de esas fichas:
    ```kotlin
    val idsEnCasilla = fichas
        .filter { it.casilla == casillaBuscada }
        .map { it.idJugador }
    ```

3.  **Agrupar todas las fichas por casilla:**
    Si vas a necesitar consultar varias casillas a menudo, es más eficiente agruparlas todas de una vez en un `Map`:
    ```kotlin
    val mapaPorCasilla = fichas.groupBy { it.casilla }
    
    // Luego accedes fácilmente:
    val fichasEnLaCinco = mapaPorCasilla[5] ?: emptyList()
    ```

### Un pequeño detalle técnico en tu clase:
En tu código tienes `val idImg: Int = null`. En Kotlin, para que un `Int` pueda ser nulo, debes marcar el tipo con un signo de interrogación: **`Int?`**. 

Debería quedar así:
```kotlin
val idImg: Int? = null
```
Si no pones el `?`, el compilador te dará un error porque un `Int` primitivo no puede contener un valor nulo.

### Explicación detallada de los cambios y la lógica:

1.  **Agrupación (`groupBy`):** La línea `val fichasPorJugador = fichas.groupBy { it.idJugador }` es lo más importante. Transforma la lista plana de fichas en un `Map<String, List<FichaSnapshot>>`. Las claves son los IDs de los jugadores y los valores son listas de todas sus fichas que estaban en esa casilla. Esto nos permite tratar a todas las fichas de un mismo jugador como una sola "pila" visual.
2.  **`idImg` y `Image`:**
    * **Corrección del tipo:** En la clase `FichaSnapshot`, he cambiado `val idImg: Int = null` por `val idImg: Int? = null`. En Kotlin, para asignar `null`, el tipo debe ser nullable (`Int?`).
    * **Carga de imagen:** Usamos `painterResource(id = fichaRepresentante.idImg!!)` para cargar la imagen correspondiente. Asumimos que `idImg` es un ID de recurso drawable válido (como `R.drawable.mi_ficha`).
    * **`ContentScale.Crop`:** Importante para que la imagen se adapte y rellene todo el círculo de 20.dp sin deformarse.
3.  **Indicador de Número (la "pila"):**
    * **Condición:** `if (fichasDelGrupo.size > 1)` asegura que el número solo aparece si hay 2, 3, etc. fichas. Si solo hay una, no se muestra nada sobre la imagen.
    * **Superposición:** El número se coloca dentro del `Box` *después* de la `Image`, por lo que se dibuja encima.
    * **Posicionamiento:** `.align(Alignment.TopEnd)` lo coloca en la esquina superior derecha de la ficha. `.offset()` se usa para ajustarlo unos píxeles para que se vea mejor (puedes jugar con estos valores).
    * **Estilo:** He usado un fondo negro semitransparente (`Color.Black.copy(alpha = 0.6f)`) en un círculo pequeño para que el número blanco resalte sobre cualquier imagen de ficha.
4.  **Tamaño y Ajustes:**
    * He aumentado el tamaño de la ficha a `20.dp` (antes `14.dp`) para que el indicador de número sea legible y no tape toda la imagen.
    * He añadido `Arrangement.spacedBy(2.dp)` al `FlowRow` para que haya un pequeño espacio entre las fichas de distintos jugadores.
    * He eliminado el `.background(color_primary)` del `Box` principal porque ahora el fondo es la propia imagen de la ficha. He dejado un borde blanco (`.border`) que ayuda a separar la ficha del tablero.

                    )
                }

                            text = grupo.size.toString(),
                            color = Color.White,
                            fontSize = 8.sp,
                            fontWeight = FontWeight.Bold
                        )
                    }
                }
            }
        }
    }
}

Aquí tienes el código refactorizado. He extraído la lógica de transformación a una lista de **`Pair<Int, FichaSnapshot>`** antes de entrar en el `FlowRow` para que el bucle sea mucho más limpio.

```kotlin
@OptIn(ExperimentalLayoutApi::class)
@Composable
fun FichasStackSnapshot(fichas: List<FichaSnapshot>) {
    // Transformamos la lista original en una lista de Pair(Cuenta, FichaRepresentativa)
    val fichasProcesadas: List<Pair<Int, FichaSnapshot>> = fichas
        .groupBy { it.idJugador }
        .map { it.value.size to it.value.first() }

    FlowRow(
        modifier = Modifier.fillMaxSize(),
        maxItemsInEachRow = 2,
        horizontalArrangement = Arrangement.Center,
        verticalArrangement = Arrangement.Center
    ) {
        fichasProcesadas.forEach { (cuenta, ficha) ->
            Box(
                modifier = Modifier
                    .fillMaxWidth(0.5f)
                    .aspectRatio(1f),
                contentAlignment = Alignment.Center
            ) {
                if (ficha.idImg != null) {
                    // Contenedor interno para que el Badge no se corte
                    Box(modifier = Modifier.fillMaxSize(0.85f)) {
                        // Imagen de la ficha
                        Image(
                            painter = painterResource(id = ficha.idImg),
                            contentDescription = null,
                            modifier = Modifier
                                .fillMaxSize()
                                .clip(CircleShape)
                                .border(1.5.dp, color_fg, CircleShape),
                            contentScale = ContentScale.Crop
                        )

                        // El "numerín" (Badge)
                        if (cuenta > 1) {
                            Box(
                                modifier = Modifier
                                    .align(Alignment.TopEnd)
                                    .fillMaxSize(0.55f)
                                    .background(color_bg, CircleShape)
                                    .border(1.dp, color_fg, CircleShape),
                                contentAlignment = Alignment.Center
                            ) {
                                Text(
                                    text = cuenta.toString(),
                                    color = color_fg,
                                    fontSize = 9.sp,
                                    fontWeight = FontWeight.Bold
                                )
                            }
                        }
                    }
                }
            }
        }
    }
}
```

### ¿Qué ha cambiado?

* **Lógica de Datos:** He creado `fichasProcesadas`. Utiliza `.map { it.value.size to it.value.first() }` para generar exactamente la estructura de `Pair` que pedías.
* **Limpieza en el Bucle:** Ahora el `forEach` desestructura directamente el Pair: `(cuenta, ficha)`. Ya no necesitas acceder a `grupo.size` ni `grupo.first()`.
* **Ajuste Visual:** He añadido un ligero margen interno en el `Box` de la ficha (`fillMaxSize(0.85f)`) para asegurar que, al ser un diseño 2x2, los bordes blancos (`color_fg`) no se toquen entre sí y el "numerín" tenga espacio para sobresalir sin pegarse al borde de la casilla.
* **Colores:** Se utilizan `color_fg` para los bordes/texto y `color_bg` para el fondo del indicador, tal como solicitaste.
