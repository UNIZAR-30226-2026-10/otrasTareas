Para que tu campo de búsqueda (`OutlinedTextField`) tenga exactamente la misma estética que el botón de la imagen (fondo azul, borde amarillo, formas redondeadas y estilo de juego), necesitamos personalizar los colores y quitar los bordes por defecto de Material Design.

Aquí tienes el código adaptado para que "herede" el estilo de tu `amigosBoton`:

```kotlin
@Composable
fun BuscarAmigoInput() {
    var textState by remember { mutableStateOf("") }

    Surface(
        color = color_secondary, // El azul de tu imagen
        shape = RoundedCornerShape(25.dp), // Totalmente redondeado
        border = BorderStroke(2.dp, color_primary), // El borde amarillo/dorado
        modifier = Modifier
            .width(250.dp)
            .height(56.dp)
    ) {
        TextField(
            value = textState,
            onValueChange = { textState = it },
            placeholder = { 
                Text(
                    "Buscar amigo...", 
                    style = SETextTypes.plano, 
                    color = color_text.copy(alpha = 0.6f) 
                ) 
            },
            leadingIcon = {
                Icon(
                    imageVector = Icons.Default.Search,
                    contentDescription = "Buscar",
                    tint = color_text,
                    modifier = Modifier.size(24.dp)
                )
            },
            singleLine = true,
            textStyle = SETextTypes.plano,
            colors = TextFieldDefaults.colors(
                focusedContainerColor = Color.Transparent,
                unfocusedContainerColor = Color.Transparent,
                disabledContainerColor = Color.Transparent,
                cursorColor = color_text,
                focusedIndicatorColor = Color.Transparent, // Quitamos la línea de abajo
                unfocusedIndicatorColor = Color.Transparent,
            ),
            modifier = Modifier.fillMaxSize()
        )
    }
}

```

### ¿Qué cambios se aplicaron para igualar la imagen?

* **De `OutlinedTextField` a `TextField` dentro de `Surface**`: El `OutlinedTextField` tiene un borde nativo difícil de ajustar al estilo "sticker" de tu juego. Usar un `Surface` con tu `color_secondary` y `border` asegura que sea idéntico al botón de Amigos.
* **Contenedor Transparente**: En los `colors` del TextField, pusimos el `containerColor` como `Transparent`. Así, el color azul que se ve es el del `Surface`.
* **Sin indicadores**: Eliminamos la línea que aparece debajo del texto al escribir con `focusedIndicatorColor = Color.Transparent`.
* **Tipografía Consistente**: He cambiado el estilo a `SETextTypes.plano` para que la fuente coincida con el resto de tu interfaz.
