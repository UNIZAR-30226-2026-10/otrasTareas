------------------

Para sustituir las líneas por imágenes estiradas (assets de serpiente y escalera) que unan los centros de las casillas, no puedes usar `drawLine`. Debes usar la función **`drawImage`** dentro del `Canvas`.

Para que la imagen se estire correctamente entre los puntos `start` y `end`, necesitamos realizar tres pasos matemáticos:
1.  **Rotar** el Canvas para que el eje X coincida con la línea que une las casillas.
2.  **Calcular la distancia** para saber cuánto estirar la imagen.
3.  **Dibujar** la imagen con el tamaño estirado (`dstSize`) en la posición correcta (`dstOffset`).

Aquí tienes el código del `Canvas` modificado para usar imágenes estiradas:

```kotlin
// ... (dentro de BoxWithConstraints y después del Column del tablero)

// Cargamos los assets una sola vez fuera del Canvas para mejorar rendimiento
val imgSerpiente = painterResource(id = R.drawable.serpiente_cuerpo) // Asegúrate de tener este asset
val imgEscalera = painterResource(id = R.drawable.escalera_cuerpo)  // Asegúrate de tener este asset

Canvas(modifier = Modifier.aspectRatio(1f).fillMaxWidth()) {
    tableroState.casillas.forEachIndexed { index, casilla ->
        // IMPORTANTE: Ajusta esta lógica si numOrigen no es index + 1
        val numOrigen = index + 1
        
        if (casilla.saltoA != null) {
            val start = getCenterOfCasilla(numOrigen, casillaPx)
            val end = getCenterOfCasilla(casilla.saltoA!!, casillaPx)

            // 1. Cálculos matemáticos para el estiramiento
            val dx = end.x - start.x
            val dy = end.y - start.y
            val distancia = kotlin.math.sqrt(dx * dx + dy * dy)
            // Ángulo en radianes para rotar el Canvas
            val anguloRad = kotlin.math.atan2(dy, dx)
            // Ángulo en grados para la rotación de Compose
            val anguloDeg = kotlin.math.toDegrees(anguloRad.toDouble()).toFloat()

            // 2. Selección de la imagen y grosor
            val painter = if (casilla.tipo == TipoCasilla.Serpiente) imgSerpiente else imgEscalera
            // Grosor visual del salto (ancho de la serpiente/escalera)
            val grosor = 15.dp.toPx() 

            // 3. Dibujo con rotación y estiramiento
            // Rotamos el Canvas alrededor del punto de origen para dibujar recto
            rotate(anguloDeg, pivot = start) {
                with(painter) {
                    draw(
                        size = Size(width = distancia, height = grosor),
                        alpha = 0.8f, // Un poco de transparencia
                        // Posicionamos para que el centro de la imagen coincida con la línea
                        dstOffset = Offset(start.x, start.y - grosor / 2),
                        // Estiramos la imagen a la distancia exacta
                        dstSize = Size(width = distancia, height = grosor)
                    )
                }
            }
        }
    }
}
```

### Explicación de los cambios:

1.  **`rotate(anguloDeg, pivot = start)`**: Esta es la clave. En lugar de calcular una línea inclinada, inclinamos el "papel" (el Canvas) y dibujamos una imagen horizontal recta que empieza en `start` y mide `distancia` de largo. Compose se encarga de la perspectiva.
2.  **`Size(width = distancia, height = grosor)`**: Usamos la `distancia` calculada como el *ancho* de la imagen estirada, y un `grosor` fijo como su *alto*.
3.  **`dstOffset`**: Ajustamos la posición vertical de la imagen restando `grosor / 2` para que el centro de la serpiente o escalera pase exactamente por el centro de las casillas, no por el borde superior de la imagen.
4.  **`dstSize`**: Fuerza a Compose a escalar el asset al tamaño calculado, creando el efecto de "estirado" entre las dos casillas.
5.  **Carga de Assets**: He movido la carga de `painterResource` fuera del `Canvas` porque cargar recursos dentro de un bucle de dibujo es muy costoso para el rendimiento.
