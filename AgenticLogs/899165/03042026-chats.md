jetpack compose como centrar un texto

Gemini ha dicho
Centrar texto en Jetpack Compose es bastante sencillo, pero la "forma correcta" depende de si quieres centrar el texto dentro de su propio contenedor o si quieres centrar el párrafo en sí mismo.

Aquí tienes las tres formas más comunes de lograrlo:

1. Centrar el párrafo (Alineación interna)
Si tu componente Text es más ancho que el contenido (por ejemplo, ocupa todo el ancho de la pantalla), usa el parámetro textAlign. Esto equivale al text-align: center de CSS.

Kotlin
Text(
    text = "Hola Compose",
    modifier = Modifier.fillMaxWidth(),
    textAlign = TextAlign.Center
)
2. Centrar el componente en un contenedor
A veces no quieres que el texto ocupe todo el ancho, sino que el "recuadro" del texto esté en el centro de la pantalla o de un layout. Para esto, usamos las propiedades del contenedor (Column, Row o Box).

En una Column:

Kotlin
Column(
    modifier = Modifier.fillMaxSize(),
    verticalArrangement = Arrangement.Center, // Centro vertical
    horizontalAlignment = Alignment.CenterHorizontally // Centro horizontal
) {
    Text(text = "Texto centrado en la columna")
}
En un Box (el más flexible):

Kotlin
Box(
    modifier = Modifier.fillMaxSize(),
    contentAlignment = Alignment.Center
) {
    Text(text = "Totalmente centrado")
}
3. La opción "Todo en uno"
Si quieres que el texto esté centrado tanto por su posición en el layout como por su alineación interna, puedes combinar Modifier con textAlign:

Kotlin
Text(
    text = "Texto centrado",
    modifier = Modifier
        .fillMaxSize() // Ocupa todo el espacio
        .wrapContentHeight(), // Centra el contenido verticalmente
    textAlign = TextAlign.Center // Centra el contenido horizontalmente
)
Resumen rápido: ¿Cuál usar?
Situación	Propiedad a usar
El texto es largo (varias líneas)	textAlign = TextAlign.Center
Quieres centrar el objeto en la pantalla	Alignment.Center (en Box o Column)
El texto está dentro de una fila (Row)	verticalAlignment = Alignment.CenterVertically

        horizontalAlignment = Alignment.CenterHorizontally

¿Por qué no se centra solo con el Surface?
El Surface en Jetpack Compose está diseñado para ser una "capa" o "superficie" (como un papel). Su función principal es:

Dar color de fondo.

Gestionar la elevación (sombras).

Definir la forma (bordes redondeados).

Como el Surface solo puede contener un hijo directo, se suele usar el Box o la Column dentro de él para decirle a ese hijo exactamente dónde sentarse.

Un pequeño truco visual
Si tu Surface no ocupa toda la pantalla y solo quieres que el texto fuerce al Surface a centrarlo, asegúrate de que el Modifier.fillMaxSize() (o el tamaño que desees) esté en el Surface y no solo en el texto.

El problema de por qué no se ve centrado es que el parámetro content del Scaffold te entrega un objeto PaddingValues que debes aplicar obligatoriamente. Si no lo usas, el contenido (tu NavHost) se dibuja "debajo" de la topBar, lo que rompe el centrado vertical de cualquier pantalla interna.

Además, el NavHost por sí mismo no tiene propiedades de alineación; es solo un contenedor de navegación. Para centrar lo que hay dentro, debes envolverlo en un layout.

Aquí tienes la solución corregida:

Kotlin
Scaffold(
    topBar = { MenuTopBar(SEState) },
    content = { padding -> // Este 'padding' es vital
        Box(
            modifier = Modifier
                .fillMaxSize()
                .padding(padding), // Aplica el margen de la topBar
            contentAlignment = Alignment.Center // Esto centrará tu NavHost/Pantallas
        ) {
            NavHost(
                navController = SEState.navController,
                startDestination = Destinos.JUGAR,
            ) {
                menuTopBarGraph()
            }
        }
    }
)
¿Por qué ocurre esto?
Padding de Scaffold: El Scaffold reserva espacio para la topBar. Si no usas Modifier.padding(padding), tu pantalla empezará desde la esquina superior izquierda absoluta del dispositivo, quedando cortada por la barra superior.

El NavHost no centra: El NavHost simplemente intercambia pantallas. Si la pantalla que carga (como tu botón de "Mazo") no tiene un Modifier.fillMaxSize(), se quedará pegada arriba a la izquierda por defecto.

El Box es la clave: Al envolver el NavHost en un Box con fillMaxSize y Alignment.Center, obligas a que cualquier contenido que el sistema de navegación decida dibujar aparezca justo en el medio del espacio disponible.

Recomendación adicional
Asegúrate de que dentro de menuTopBarGraph(), la pantalla correspondiente a Destinos.JUGAR no tenga otro Modifier.fillMaxSize() que sobreescriba este comportamiento, o si lo tiene, que esa pantalla también use un Box o Column centrados.

2. Configurar el Scaffold con WindowInsets
El Scaffold es inteligente: si le pasas los contentWindowInsets, él calculará automáticamente cuánto espacio ocupan la barra de estado (arriba) y la de navegación (abajo).

Modifica tu Scaffold así:

    contentWindowInsets = WindowInsets.safeDrawing

¿Qué está pasando ahora?
enableEdgeToEdge(): Evita que el sistema ponga barras negras arriba o abajo, permitiendo que tu fondo se vea en toda la pantalla.

WindowInsets.safeDrawing: Es la forma moderna de decirle al Scaffold: "Ten en cuenta la cámara frontal, el notch y la rayita de navegación de Android".

Si lo que buscas es que las barras desaparezcan por completo (como en un juego o un vídeo) para que tu app ocupe el 100% de la pantalla real, necesitas activar el Modo Inmersivo.

En Compose, esto se hace interactuando con la ventana (Window) y el WindowInsetsController.

La solución: Ocultar barras del sistema
Debes añadir este código en tu MainActivity.kt, dentro de onCreate, para que el sistema oculte las barras automáticamente:

Kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    
    // 1. Configurar la ventana para que el contenido pase por debajo
    WindowCompat.setDecorFitsSystemWindows(window, false)

    // 2. Controlador para ocultar las barras
    val controller = WindowInsetsControllerCompat(window, window.decorView)
    
    // Oculta tanto la barra de estado (arriba) como la de navegación (abajo)
    controller.hide(WindowInsetsCompat.Type.systemBars())
    
    // Configura el comportamiento para que aparezcan solo si el usuario desliza desde el borde
    controller.systemBarsBehavior = 
        WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE

    setContent {
        // Tu código de Compose...
    }
}
¿Cómo afecta esto a tu layout?
Una vez que las barras están ocultas, ya no necesitas los paddings de seguridad que intentábamos poner antes, porque ahora quieres que tu fondo toque los bordes del cristal del móvil.

Elimina modifier.padding(paddingValues) del NavHost si quieres que el fondo de tu pantalla ignore el espacio de las barras.

Quita statusBarsPadding() de tu TopBar si quieres que esta se pegue al borde superior físico del teléfono.

Advertencia sobre el "Notch" (Cámaras en pantalla)
Si ocultas las barras, es posible que la cámara frontal (el agujerito negro) tape parte de tu MenuTopBar. Si eso ocurre, puedes añadir este atributo en tu AndroidManifest.xml (dentro de tu <activity>) para forzar que el contenido use el área del "corte":

XML
android:windowLayoutInDisplayCutoutMode="shortEdges"
¿Cuál es tu objetivo final?
Si es un juego: Usa el código de arriba (Modo Inmersivo).

Si es una app normal: No se recomienda ocultarlas siempre, porque el usuario pierde de vista la hora y la batería. En ese caso, lo mejor es ponerles un color sólido que combine con tu app.

Añadir padding a una Row es muy directo. Al igual que con cualquier otro componente en Compose, se utiliza el Modifier.padding().

Aquí tienes las formas más comunes de aplicarlo dependiendo de lo que necesites:

1. Padding uniforme en todos los lados

Kotlin

    Text("Elemento 2")

2. Padding específico (Horizontal y Vertical)
Ideal si quieres que los elementos no toquen los bordes laterales pero tengan menos espacio arriba y abajo:

Kotlin
Row(
    modifier = Modifier.padding(horizontal = 20.dp, vertical = 10.dp)
) {
    // Contenido
}
3. Padding asimétrico (Lado por lado)
Si necesitas medidas distintas para cada dirección:

Kotlin
Row(
    modifier = Modifier.padding(
        start = 8.dp, 
        top = 16.dp, 
        end = 24.dp, 
        bottom = 4.dp
    )
) {
    // Contenido
}
Un truco útil: Espaciado entre elementos
A menudo, cuando pedimos padding para una Row, lo que realmente queremos es que los elementos de dentro no estén pegados entre sí. En lugar de ponerle padding a cada Text o Icon, usa Arrangement.spacedBy:

Kotlin
Row(
    modifier = Modifier
        .fillMaxWidth()
        .padding(16.dp), // Margen exterior de la fila
    horizontalArrangement = Arrangement.spacedBy(12.dp) // Espacio FIJO entre hijos
) {
    BotonMazo("Mazo 1")
    BotonMazo("Mazo 2")
}
¿Qué diferencia hay?
Modifier.padding: Es el espacio fuera de los elementos de la fila (el margen interno de la fila misma).

Arrangement.spacedBy: Es el espacio entre los elementos que están dentro de la fila.

como centrar el contenido deun surface verticalmente

Gemini ha dicho
Para centrar el contenido verticalmente dentro de un Surface, la forma más eficiente es utilizar un contenedor intermedio como un Box o una Column, ya que el Surface no tiene una propiedad nativa de alineación de contenido.

Aquí tienes las tres mejores formas de hacerlo:

1. Usando un Box (La más directa)
El Box permite usar contentAlignment. Al ponerlo en Alignment.Center, centrará el contenido tanto horizontal como verticalmente.

Kotlin
Surface(modifier = Modifier.fillMaxSize()) {
    Box(
        contentAlignment = Alignment.Center // Centro absoluto
    ) {
        Text("Texto centrado vertical y horizontalmente")
    }
}
2. Usando una Column (Si quieres control total)
Si solo quieres centrarlo verticalmente pero que permanezca a la izquierda (o si tienes varios elementos uno debajo de otro), usa verticalArrangement.

Kotlin
Surface(modifier = Modifier.fillMaxSize()) {
    Column(
        verticalArrangement = Arrangement.Center, // Centro vertical
        horizontalAlignment = Alignment.Start    // Alineado a la izquierda
    ) {
        Text("Lobby")
        Text("Jugadores: 5")
    }
}
3. Usando Modificadores en el propio hijo
Si no quieres usar un contenedor extra, puedes pedirle al propio elemento que se centre ocupando todo el espacio del Surface y alineando su contenido interno.

Kotlin
Surface(modifier = Modifier.fillMaxSize()) {
    Text(
        text = "Centrado con modificadores",
        modifier = Modifier
            .fillMaxSize()
            .wrapContentHeight(Alignment.CenterVertically), // El truco para el centro vertical
        textAlign = TextAlign.Center // Centro horizontal
    )
}
¿Cuál elegir para tu lobby()?
Dado que mencionaste que quieres que el lobby() aparezca a la izquierda, la Opción 2 es la mejor. Al usar la Column con Arrangement.Center, el contenido bajará hasta la mitad de la pantalla, pero se mantendrá pegado al borde izquierdo.

Resumen de alineaciones en Horizontal (Landscape)
Como tu app es horizontal, el centro vertical es un espacio más estrecho. Asegúrate de que el Surface tenga aplicado el padding(paddingValues) del Scaffold para que el centro sea el centro real del área visible y no se vea desplazado por la TopBar.

Para oscurecer una imagen en Jetpack Compose, la forma más sencilla es usar el parámetro alpha (transparencia) en el composable Image o aplicar un filtro de color oscuro (un "tinte") sobre ella.

Aquí tienes las dos mejores formas de hacerlo para que el contenido que pongas encima (como el icono del lápiz en tu tablero) resalte más:

Opción 1: Usar alpha (Transparencia)
Esta opción hace que la imagen se vuelva más transparente, permitiendo que el color de fondo del contenedor se mezcle. Si el fondo es negro o azul oscuro, la imagen se verá oscurecida.

Kotlin
Image(
    painter = painterResource(id = R.drawable.tu_imagen_tablero),
    contentDescription = "Tablero de juego",
    modifier = Modifier.fillMaxSize(),
    contentScale = ContentScale.Crop,
    // Un alpha de 0.5f hace que la imagen sea 50% transparente.
    // Esto la oscurecerá si el fondo del Box o Surface es oscuro.
    alpha = 0.5f 
)
Por qué funciona: Al hacer la imagen transparente, se ve más el color del contenedor que está "detrás". Si tu Surface o Box tiene un color oscuro como Color(0xFF0D1117), la imagen se oscurecerá sutilmente.

Opción 2: Usar un ColorFilter (Tinte)
Esta opción es más precisa porque aplica directamente una capa de color oscuro sobre la imagen. Puedes elegir cualquier color, como negro o azul marino, y la intensidad de la mezcla.

Kotlin
Image(
    painter = painterResource(id = R.drawable.tu_imagen_tablero),
    contentDescription = "Tablero de juego",
    modifier = Modifier.fillMaxSize(),
    contentScale = ContentScale.Crop,
    // Filtro de color negro con una opacidad del 40% (0.4f).
    // El BlendMode.Darken es perfecto para este efecto.
    colorFilter = ColorFilter.tint(
        Color.Black.copy(alpha = 0.4f), 
        blendMode = BlendMode.Darken
    )
)
Por qué funciona: El ColorFilter.tint toma un color (negro con un 40% de opacidad) y lo mezcla con cada píxel de la imagen usando el BlendMode.Darken, logrando un efecto de oscurecimiento uniforme que hace que cualquier elemento blanco (como el icono del lápiz) resalte dramáticamente.

Para centrar los objetos dentro de una Column, tienes dos ejes que controlar: el vertical (eje principal) y el horizontal (eje secundario).

Aquí tienes cómo hacerlo dependiendo de lo que busques:

1. Centrado Total (Vertical y Horizontal)
Si quieres que todos los elementos de la columna estén justo en el medio del espacio disponible:

Kotlin
Column(
    modifier = Modifier.fillMaxSize(),
    verticalArrangement = Arrangement.Center, // Centro vertical
    horizontalAlignment = Alignment.CenterHorizontally // Centro horizontal
) {
    Text("Elemento 1")
    BotonMazo("Lategame")
}
2. Solo Centrado Horizontal
Si quieres que los elementos estén arriba del todo, pero centrados de izquierda a derecha:

Kotlin
Column(
    modifier = Modifier.fillMaxWidth(),
    horizontalAlignment = Alignment.CenterHorizontally
) {
    Text("Arriba pero al centro")
}
3. Solo Centrado Vertical
Si quieres que los elementos estén a la izquierda (por defecto), pero centrados de arriba a abajo:

Kotlin
Column(
    modifier = Modifier.fillMaxHeight(),
    verticalArrangement = Arrangement.Center
) {
    Text("A la izquierda pero centrado verticalmente")
}
Diferencias clave:
verticalArrangement: Controla cómo se distribuyen los hijos a lo largo de la columna. Puedes usar Arrangement.Center, Arrangement.SpaceBetween (separados), o Arrangement.Bottom (todos abajo).

Si tienes una columna donde casi todo va a la izquierda, pero un solo objeto debe ir al centro, no cambies toda la columna. Usa el modificador en ese objeto específico:

Kotlin

Para añadir espacio entre los elementos de una Column o una Row en Jetpack Compose, tienes dos estrategias principales: usar un espaciado automático para todos los elementos o insertar espacios manuales entre ellos.

Aquí tienes cómo hacerlo:

1. Espaciado automático (Arrangement.spacedBy)
Es la forma más limpia y profesional. En lugar de añadir márgenes a cada objeto, le dices al contenedor que separe a todos sus hijos por la misma cantidad.

En una Column (vertical):

Kotlin
Column(
    modifier = Modifier.padding(16.dp),
    verticalArrangement = Arrangement.spacedBy(12.dp) // Añade 12.dp entre cada hijo
) {
    BotonMazo("Lategame")
    TarjetaTablero()
    Text("Más contenido")
}
En una Row (horizontal):

Kotlin
Row(
    horizontalArrangement = Arrangement.spacedBy(20.dp) // Añade 20.dp entre cada hijo
) {
    BotonMazo("Mazo 1")
    BotonMazo("Mazo 2")
}
2. Espacios manuales (Spacer)
Si necesitas que el espacio no sea uniforme (por ejemplo, mucho espacio entre el primero y el segundo, pero poco entre los demás), usa el componente Spacer.

Kotlin
Column {
    Text("Título")
    Spacer(modifier = Modifier.height(30.dp)) // Gran espacio vertical
    Text("Subtítulo")
    Spacer(modifier = Modifier.height(8.dp))  // Espacio pequeño
    BotonMazo("Jugar")
}
3. Distribución proporcional (Weight)
Si quieres que los objetos se separen ocupando todo el espacio disponible (por ejemplo, uno arriba y otro abajo, dejando el centro vacío), usa el modificador weight.

Kotlin
Column(modifier = Modifier.fillMaxHeight()) {
    Text("Elemento Superior")
    
    Spacer(modifier = Modifier.weight(1f)) // Este spacer "empuja" al resto
    
    Text("Elemento Inferior")
}
Resumen: ¿Cuál usar?
Arrangement.spacedBy: Úsalo cuando todos los botones o elementos deben estar a la misma distancia (como en un menú).

Spacer: Úsalo para huecos específicos o si el diseño es muy asimétrico.

¿Por qué hacerlo así?
Independencia: Al usar Box con Alignment.Center para el contenido principal y Alignment.CenterEnd para los amigos, el lobby se queda exactamente en el eje central de la pantalla, sin importar lo ancho que sea el componente de amigos.

Vertical: He añadido verticalAlignment = Alignment.CenterVertically a la Row central para que los grupos de jugadores y el tablero estén alineados por el medio, lo que suele quedar mejor en pantallas horizontales.

Limpieza: No necesitas añadir Spacers extra al final de la fila que podrían desequilibrar el peso visual.

Para centrar elementos en una Row, tienes que gestionar dos ejes: el horizontal (que es el eje principal o Main Axis) y el vertical (que es el eje secundario o Cross Axis).

Aquí tienes las propiedades exactas que debes usar en el constructor de la Row:

1. Centrado Horizontal (horizontalArrangement)
Esto controla cómo se distribuyen los hijos de izquierda a derecha.

Kotlin
Row(
    modifier = Modifier.fillMaxWidth(),
    horizontalArrangement = Arrangement.Center // Todos los elementos al centro horizontal
) {
    Text("Uno")
    Text("Dos")
}
2. Centrado Vertical (verticalAlignment)
Esto controla cómo se alinean los hijos de arriba a abajo dentro del alto de la fila.

Kotlin
Row(
    modifier = Modifier.height(100.dp), // Necesita tener un alto para notar el centrado
    verticalAlignment = Alignment.CenterVertically // Todos los elementos al centro vertical
) {
    Text("Centrado verticalmente")
}
3. Centrado Total (Ambos ejes)
Si quieres que todo el bloque de contenido esté perfectamente en medio del espacio disponible de la fila:

Kotlin
Row(
    modifier = Modifier.fillMaxWidth().height(100.dp),
    horizontalArrangement = Arrangement.Center,     // Centro X
    verticalAlignment = Alignment.CenterVertically    // Centro Y
) {
    // Tus componentes aquí
}
Casos especiales que te pueden servir:
Espaciado uniforme: Si quieres que estén centrados pero con espacio entre ellos, usa Arrangement.spacedBy(20.dp) junto con un Box o Column padre que esté centrado.

Alinear solo un elemento: Si quieres que toda la Row esté arriba pero un icono específico esté centrado verticalmente, usa el modificador en el hijo:

Kotlin
Icon(
    ...,
    modifier = Modifier.align(Alignment.CenterVertically)
